# Campaign Performance Check

## When This Runs

- **Standalone:** `/revops-watchdog campaign-performance-check {campaign-name-or-utm}`
- **Typical cadence:** 2-4 weeks post-campaign launch; again at 60 and 90 days
  for campaigns with longer sales cycles

## Inputs

- Campaign identifier (campaign name, UTM string, or HubSpot Campaign ID)
- HubSpot Campaign object data (if the campaign has an associated Campaign)
- Contacts with matching `utm_campaign` or Campaign membership
- Deals associated with those contacts
- The forecast file: `campaign-forecast-{campaign-name}-*.md`

## Cross-Agent Input: campaign-forecaster Output

Locate the specific forecast file. Search paths:
- `docs/campaign-forecast-*.md`
- `outputs/campaign-forecast-*.md`
- `.claude/outputs/campaign-forecast-*.md`

Extract from the forecast:
- Campaign name and identifier
- Forecast period (date range)
- Channel-by-channel projections (impressions, clicks, leads per channel)
- Lead funnel projection (engaged → MQL → SAL → SQL → pipeline)
- ROI estimate
- Key assumptions
- Confidence level / risk factors
- Benchmark comparisons

If no forecast file exists for the campaign, this skill cannot run fully.
Either:
- Prompt the user to provide forecast numbers manually, OR
- Exit with a note that a forecast is required for this skill

## Analysis Framework

### 1. Actual Performance

Pull actuals from HubSpot for the campaign period:

**Channel-level (if UTMs are tagged correctly):**
- Clicks / sessions per utm_source (requires GA4 or session data)
- Leads created with matching utm_campaign
- Cost per channel (from ad platform data if linked)

**Funnel progression (from HubSpot):**
- Contacts with campaign attribution
- Converted to MQL (by source type: P1, P2, Outbound)
- Converted to SAL (Scheduled Demo Calls)
- Converted to SQL (Demos Completed)
- Pipeline value generated
- Closed won to date (if in analysis window)

### 2. Variance Calculation

For each forecasted metric, calculate:
- Actual value
- Forecast value
- Absolute variance
- Percentage variance
- Verdict: Below (>15% under), At (±15%), Above (>15% over) forecast

### 3. Funnel Conversion Variance

Compare actual vs. forecast conversion rates at each step:

| Stage Transition | Forecast CVR | Actual CVR | Δ | Comment |
|-----------------|-------------|------------|---|---------|
| Click → Lead | {pct}% | {pct}% | {pp} | {commentary} |
| Lead → MQL | {pct}% | {pct}% | {pp} | |
| MQL → SAL | {pct}% | {pct}% | {pp} | |
| SAL → SQL | {pct}% | {pct}% | {pp} | |

### 4. Assumption Validation

For each key assumption in the forecast, state whether it held:
- E.g., "Forecast assumed $8 CPM on LinkedIn; actual $14 CPM — assumption
  INVALID"
- E.g., "Forecast assumed 3% CTR on Google ads; actual 3.2% — assumption
  HELD"

### 5. ROI Comparison

- Forecasted ROI / pipeline / CAC
- Actual ROI / pipeline / CAC (based on data to date)
- Time-to-breakeven projection

### 6. Risk Factor Check

For each risk factor flagged in the forecast, note whether it materialized.

## Anomaly Table Writes

INSERT one row into `anomalies` with `surface='campaign'`:
- Severity MED if overall variance >25% in either direction
- Severity LOW if within ±25%
- Flag in description: "{campaign} actual vs. forecast: {summary}"

This is informational more than corrective — actual vs. forecast variance
is a learning signal, not usually an alert.

## Handoff

One handoff to chief-of-staff summarizing verdict (Below / At / Above forecast)
and any major learning worth surfacing in the weekly or monthly brief.
Flag if the learning affects other agents:
- performance-marketer: calibration data for creative / channel-level decisions
- gtm-fleet: input for next campaign-forecaster run

## Multi-Check Pattern

For campaigns with longer sales cycles, run this skill multiple times:
- **T+2 weeks:** Top-of-funnel actuals (leads, MQLs)
- **T+6 weeks:** Mid-funnel actuals (SALs, SQLs)
- **T+90 days:** Full-funnel actuals including pipeline realization

Each run appends to the analysis; the 90-day check is the authoritative
outcome for forecast calibration purposes.
